Prerequisites & Setup Requirements

System requirements and dependencies needed to run the ETL validation framework

System Requirements
  • Python 3.8 or higher - Core runtime
  • pip package manager - Dependency management
  • 4GB RAM minimum (8GB recommended)
  • Network connectivity - Database & cloud access
  • Modern web browser - Chrome, Firefox, Edge
Database Drivers
  • pyodbc ≥4.0.39 - SQL Server & Azure SQL
  • pymysql ≥1.1.0 - MySQL databases
  • psycopg2 ≥2.9.0 - PostgreSQL
  • oracledb ≥1.4.0 - Oracle databases
  • pymongo ≥4.6.0 - MongoDB
  • cassandra-driver ≥3.29.0 - Cassandra
Cloud Platforms
  • boto3 ≥1.34.0 - AWS S3 & services
  • azure-storage-blob ≥12.19.0 - Azure Blob
  • google-cloud-storage ≥2.14.0 - GCP Storage
  • databricks-sql-connector ≥3.0.0 - Databricks
Databricks Setup
  • Workspace URL - Azure/AWS Databricks URL
  • HTTP Path - SQL Warehouse or Cluster path
  • Personal Access Token (PAT) - Authentication
  • Azure AD OAuth - Client ID/Tenant (Optional)
  • Running SQL Warehouse - Or active cluster
Core Libraries
  • FastAPI ≥0.104.0 - Modern web framework
  • Uvicorn - ASGI server (Backend API)
  • Pydantic ≥2.0.0 - Data validation
  • Pandas ≥2.0.0 - Data processing
  • openpyxl ≥3.1.0 - Excel file support
  • Pytest ≥7.4.0 - Testing framework
  • Requests ≥2.31.0 - HTTP client
  • python-dotenv ≥1.0.0 - Environment config
  • python-multipart - File upload support
